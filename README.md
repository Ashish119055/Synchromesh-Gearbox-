# સિંક્રોમેશ ગિયરબોક્સ સિમ્યુલેટર

5-સ્પીડ મેન્યુઅલ ગિયરબોક્સનું ગુજરાતી ઇન્ટરેક્ટિવ સિમ્યુલેટર. ક્લચ દબાવો, ગિયર બદલો અને જુઓ કે પિત્તળની સિંક્રો (બ્લૉકર) રિંગ ઘર્ષણથી ગિયર અને શાફ્ટની ઝડપ કેવી રીતે સરખી કરે છે.

An interactive synchromesh gearbox simulator in Gujarati.

## શું છે

- ઇનપુટ શાફ્ટ, કાઉન્ટર શાફ્ટ, મુખ્ય શાફ્ટ, ગિયર, હબ, સ્લીવ, બ્રાસ રિંગ, ડૉગ દાંત અને શિફ્ટ ફોર્કનું ચાલતું કટઅવે ચિત્ર
- ક્લચ, બ્રેક અને એક્સિલરેટર પેડલ (દબાવી રાખો)
- H-પેટર્ન ગિયર લીવર: 1–5, R, N
- દરેક ગિયરની ઝડપ (rpm), એન્જિન RPM મીટર અને "ઝડપ મેળ" બાર
- ગિયર બદલવાના 5 પગલાં, ધીમી ગતિ, ઑટો ડેમો
- ક્લચ દબાવ્યા વગર ગિયર બદલો તો ગ્રાઇન્ડ; સરળ મોડ બંધ હોય તો એન્જિન સ્ટૉલ પણ થઈ શકે
- કોઈ ભાગ પર ટેપ કરતાં તેનું કામ ગુજરાતીમાં

## કેવી રીતે ચલાવવું

`index.html` બ્રાઉઝરમાં ખોલો. કોઈ ઇન્સ્ટોલ કે સર્વર જરૂરી નથી.

GitHub Pages પર મૂકવા: **Settings → Pages → Branch: `main` / root** પસંદ કરો.

કીબોર્ડ: `Space` ક્લચ, `↑` એક્સિલરેટર, `↓` બ્રેક, `1`–`5`, `R`, `N` ગિયર.

## ફાઈલો

- `src/simulator.html`: પેજનો સોર્સ (HTML, CSS, JavaScript એક જ ફાઈલમાં)
- `index.html`: `src/simulator.html` ને પૂરા HTML ડૉક્યુમેન્ટમાં લપેટેલું, સીધું ખોલી શકાય તેવું
