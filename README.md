# સિંક્રોમેશ ગિયરબોક્સ લેબ · Synchromesh Gearbox Lab

5-સ્પીડ મેન્યુઅલ સિંક્રોમેશ ગિયરબોક્સનું ગુજરાતી 3D સિમ્યુલેટર, ITI મિકેનિક ડીઝલ / MMV તાલીમાર્થીઓ માટે.
ક્લચ દબાવો, ગિયર બદલો અને અંદર જુઓ કે બ્રાસ (બ્લૉકર) રિંગ ઘર્ષણથી ઝડપ કેવી રીતે સરખી કરે છે.

## વિભાગ

- **🎬 ડેમો:** 6 પ્રકરણનું ડેમોન્સ્ટ્રેશન (પાવર ફ્લો, સિંક્રો ખોલીને, સિંક્રોમેશનું કામ, દરેક ગિયર, ક્લચ વગર ગિયર, ડ્રાઇવ). "બધું શરૂઆતથી" એક પછી એક બધાં પ્રકરણ ચલાવે છે.

- **🛠️ સિમ્યુલેટર**
  - 3D મૉડલ, અસલી રંગ સાથે, 60 થી વધુ ભાગ (8 જૂથ):
    - એન્જિન બાજુ: બ્લૉક, ક્રેન્ક ફ્લેન્જ, ફ્લાયવ્હીલ, રિંગ ગિયર, બોલ્ટ, ડોવેલ, પાઇલટ બેરિંગ, સ્ટાર્ટર
    - ક્લચ: ક્લચ પ્લેટ, ઘર્ષણ લાઇનિંગ, ડૅમ્પર સ્પ્રિંગ, હબ, પ્રેશર પ્લેટ, ડાયાફ્રામ સ્પ્રિંગ, કવર, ડ્રાઇવ સ્ટ્રેપ, રિલીઝ બેરિંગ, ગાઇડ સ્લીવ, રિલીઝ ફોર્ક, કેબલ
    - શાફ્ટ અને ગિયર, આઇડલર
    - સિંક્રો: હબ, સ્લીવ, બ્રાસ રિંગ, સ્ટ્રટ, સ્ટ્રટ સ્પ્રિંગ, કોન અને ડૉગ દાંત
    - લીવર, બૂટ, શિફ્ટ ટાવર, ફોર્ક, નાયલોન પૅડ, રેલ, ડિટેન્ટ, ઇન્ટરલૉક, રિવર્સ સ્વિચ
    - બૉલ / રોલર / નીડલ બેરિંગ, સર્કલિપ, થ્રસ્ટ વૉશર, ઓઇલ સીલ
    - કેસિંગ, બેલ હાઉસિંગ, એક્સ્ટેન્શન, બોલ્ટ, ગિયર ઓઇલ, ડ્રેઇન પ્લગ, ફિલર, બ્રીધર, સ્પીડો ગિયર, માઉન્ટ, ફ્લેન્જ, UJ, પ્રોપેલર શાફ્ટ
  - કેસિંગ: કટઅવે / પારદર્શક / બંધ; 💥 છૂટું (એક્સપ્લોડેડ) દૃશ્ય
  - 🔎 શાફ્ટ ઓળખો: ઇનપુટ (લીલો), કાઉન્ટર (વાદળી), આઉટપુટ (લાલ) શાફ્ટ, ફરતાં તીર અને rpm
  - 🔬 સિંક્રો ખોલો: ફક્ત 1–2 સિંક્રો, ભાગ છૂટા, દરેક પર નામ (સ્લીવ, હબ, સ્પ્લાઇન, સ્ટ્રટ, રિંગ, કોન, ડૉગ દાંત)
  - 📌 ક્લચ લૉક: માઉસ કે એક આંગળીથી પણ ક્લચ દબાયેલો રાખી ગિયર બદલી શકાય
  - ફેરવો, ઝૂમ કરો, કોઈ પણ ભાગ પર ટેપ કરી નામ અને વિગત જુઓ
  - ગિયર લીવર (1–5, R, N), ક્લચ / બ્રેક / રેસ પેડલ, RPM મીટર, ઝડપ
  - **સિંક્રો નજીકથી:** સ્લીવ, બ્લૉકર રિંગ અને ડૉગ દાંતનું ચાલતું ચિત્ર અને ઝડપ મેળ
  - પાવર ફ્લો ચમક, શીખવાના રંગ, ધીમી ગતિ, દરેક ગિયર પર rpm લેબલ
  - ક્લચ વગર ગિયર બદલો તો ઘસારો (ગ્રાઇન્ડ); અસલી મોડમાં એન્જિન સ્ટૉલ
  - એન્જિન અને ગિયરનો અવાજ
  - 6 ગાઇડેડ ડેમો (નવા: "શરૂઆતથી: પાવર ક્યાંથી ક્યાં જાય?" અને "સિંક્રો ખોલીને જુઓ") (લખાણ + વૈકલ્પિક અવાજ), ભાગ ઓળખો રમત
- **📘 થિયરી:** ગિયરબોક્સ કેમ, પ્રકાર, ઇનપુટ-આઉટપુટ શાફ્ટ એક લાઇનમાં કેમ, સ્પ્લાઇન / હબ / સ્લીવ એટલે શું, ભાગો, સિંક્રોમેશનું કામ, ગિયર રેશિયો સૂત્ર અને આ ગિયરબોક્સનું કોષ્ટક, પાવર ફ્લો, ડબલ ડી-ક્લચિંગ, ઇન્ટરલૉક / ડિટેન્ટ, ખામીઓ, જાળવણી
- **📝 MCQ:** 43 પ્રશ્નો સમજૂતી સાથે, ખોટા પ્રશ્નો ફરી

મોબાઇલમાં 3D મૉડલ અને કંટ્રોલ એક જ સ્ક્રીનમાં આવી જાય છે; કમ્પ્યુટર પર ફુલ સ્ક્રીનમાં ખૂલે છે. લાઇટ / ડાર્ક થીમ.

## કેવી રીતે ચલાવવું

`index.html` ને Chrome, Edge કે Firefox માં ખોલો. three.js અને ફોન્ટ CDN થી લોડ થાય છે, એટલે ઇન્ટરનેટ જોઈએ.

વેબસાઇટ તરીકે મૂકવા: **Settings → Pages → Deploy from a branch → `main` / root**.

કીબોર્ડ: `Space` ક્લચ, `↑` રેસ, `↓` બ્રેક, `1`–`5`, `R`, `N` ગિયર.

## ફાઈલો

- `src/app.html`: સોર્સ (HTML, CSS, JavaScript એક જ ફાઈલમાં)
- `index.html`: `src/app.html` ને પૂરા HTML ડૉક્યુમેન્ટમાં લપેટેલું, સીધું ખોલી શકાય તેવું
